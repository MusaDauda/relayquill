## [0.1.0] - 2026-11-18

### Added

#### Core Platform Architecture & Guarantees
- **Four-Stage Verifiable Delivery Evidence**: Strict separation across `accepted` (atomic PostgreSQL `READ COMMITTED` admission and transactional outbox reservation), `published` (durable NATS JetStream `PubAck` observation with deterministic `rq:<outbox_id>:<generation>` message IDs), `http_acknowledged` (DNS-pinned HTTPS `2xx` transport observation), and `consumer_processed` (cryptographically verified `receiver_local_commit_v1` receipt).
- **Atomic Idempotency & Lost-Response Recovery**: Canonical RFC 8785 command fingerprinting (`relayquill.command.v1`, `relayquill.effective.v1`), `business_key` deduplication (`201 Created` on first admission, `200 OK` on byte-identical replay, `409 Conflict` on mutated payload), and `POST /api/v1/events/resolve` recovery for `acceptance_unknown` transport timeouts.
- **Lossless JSON & Bounded Schema Evaluation (`@relayquill/event-schema`)**: Strict UTF-8 parser rejecting duplicate object keys and lone surrogates, `lossless-json` numeric token preservation (`LosslessNumber`, 128-digit exact decimal normalizer with exponent range `[-1024, 1024]`), bounded JSON Schema 2020-12 validator (`relayquill.event-schema.v1`), off-thread `worker_threads` pool (`SchemaWorkerPool`), RFC 6901 JSON Pointer filter AST (`relayquill.filter.v1`), strict ordering key extractor (`relayquill.ordering-extractor.v1`), and derived representation v2 projections (`relayquill.lossless-projection.v1`).
- **Hierarchical WDRR Dispatch, Rate Governance & Circuit Breaking (`@relayquill/application`)**: Tenant -> Project -> Endpoint Weighted Deficit Round Robin (WDRR) scheduler, exact integer microtoken rate-bucket accounting (`1,000,000` microtokens per request with remainder numerator conservation), per-endpoint circuit-breaker state machine (`closed` -> `open` -> `half_open` single-probe gating), monotonic deadline guards, and strict per-key contiguous sequence watermarks (`unordered` and `strict_per_key`).
- **Two-Person Reviewed Replay, Ordering Skip & Recovery**: Distinct proposer-versus-reviewer (`proposer !== reviewer`) enforcement with operation-bound WebAuthn step-up verification for dead-letter replay proposals (`replay_exact_original`, `replay_with_reviewed_representation`), strict ordering gap resolution (`replay_append`, `reviewed_skip_without_processing_claim`), delivery suppression, and `rq_recovery` quarantine operations.

#### Shared Packages & Public SDKs (`packages/*`)
- `@relayquill/domain`: Pure zero-Node-builtin domain models, nominal UUID brand codecs, pipeline and governance state machines, monotonic/UTC time helpers (`@js-temporal/polyfill`), and typed domain errors.
- `@relayquill/contracts`: Pure zero-Node-builtin HTTP response envelopes, capability registry (`CAPABILITY_ACTION_REGISTRY`), signed/unsigned pagination cursors (`<= 1024` bytes), bounded SSE watch frame codecs (`<= 8 KiB`), RFC 8785 canonical command builders, webhook wire envelopes (`v1` 552-byte golden profile and `v2` derived representations), and Draft 2020-12 JSON schemas and test vectors (`contracts/`).
- `@relayquill/runtime`: Schema-validated role configuration loader (`development_trusted_local`, `portable_pglite`, `self_hosted`, `release`, plus optional remote dev profiles), cross-platform protected IPC (Win32 Named Pipes with `SetSecurityInfo` protected DACL and POSIX `0700`/`0600` Unix domain sockets), non-serializing `SecretHandle` custody (`mounted_file`, `env_file`, `env_reference`, `local_ipc`), graceful drain lifecycle, and OpenTelemetry trace propagation.
- `@relayquill/signing`: 25-field length-prefixed `rq.webhook-signature.v1` HMAC-SHA256 signer and constant-time verifier, single-occurrence `rawHeaders` validator, key rotation lifecycle (`pending`, `active`, `overlap`, `retired`, `revoked`), `204` endpoint ownership proof (`rq.endpoint-proof.v1`), and `receiver_local_commit_v1` receipt signer/verifier (`rq.receiver-receipt.v1`).
- `@relayquill/egress`: Strict WHATWG HTTPS URL normalizer (`url_v1`), offline content-addressed IANA IPv4/IPv6 special-purpose CIDR deny list (`packages/egress/artifacts/iana-special-purpose.v1.json`), isolated per-attempt DNS resolver failing closed on any private/reserved A or AAAA record, and single-use pinned TLS connector verifying socket peer IP prior to header or body transmission.
- `@relayquill/broker`: Standard `@nats-io/transport-node` and `@nats-io/jetstream` adapter supporting native TLS, Ed25519 NKey callbacks, and `.creds` authentication, non-destructive `RELAYQUILL_EVENTS_V1` / `RELAYQUILL_FANOUT_V1` topology verification, and high-fidelity offline `InMemoryJetStreamBroker`.
- `@relayquill/auth`: WebAuthn passkey registration/authentication (`@simplewebauthn/server`) with human-readable account labels, preauth challenges and enrollment intents, `__Host-rq_session` sessions, refresh-safe derived CSRF tokens (`rq.csrf.v1`), operation-bound step-up proofs, `rq_p1` machine producer credentials, and scoped RBAC with explicit `human_data_grants`.
- `@relayquill/postgres`: Standard `pg` pool and portable `@electric-sql/pglite` (`btree_gist`) adapter, custom OID `1184`/`1114`/`20` parsers, ranked `READ COMMITTED` transactions with bounded jittered retries on `55P03`/`40P01`/`40001`, and typed repositories backed by `rq` `SECURITY DEFINER` stored procedures.
- `@relayquill/producer-sdk`: Self-contained zero-Node-builtin ESM SDK (`prepareEvent`, `submitEvent`, `resolvePreparedEvent`, `getEvent`, `watchEvents`) bundled with `esbuild` and verified with `@microsoft/api-extractor`.
- `@relayquill/receiver-sdk`: Self-contained ESM SDK (`verifyWebhookRequest`, `handleEndpointProofChallenge`, `createSignedDeliveryReceipt`, `executeIdempotentDelivery`) for external webhook receivers.

#### Applications, Console & Independent Authorities (`apps/*`, `examples/*`)
- `@relayquill/api`: Fastify control plane, event admission, lost-response resolution, topology governance, and authenticated SSE watch server.
- `@relayquill/relay`, `@relayquill/fanout`, `@relayquill/sender`, `@relayquill/coordinator`: Dedicated background worker roles for outbox publication, ordered subscription matching, WDRR rate-governed pinned HTTPS delivery, and lease/retention/recovery maintenance.
- `@relayquill/admin`: Operator CLI for explicit schema migrations (`db migrate`), JetStream topology provisioning (`broker ensure`), local IPC secret custody (`provider serve`), read-only causal diagnostics (`diagnostics`), and two-person isolated recovery (`recovery`).
- `@relayquill/console`: React 19 + Vite WCAG AA operator console featuring passkey enrollment and step-up flows, 5 separate evidence-stage summary cards, schema-aware lossless event publish editor, delivery attempt and pinned-egress inspector, 6-step endpoint onboarding wizard, two-person replay approval diffs, and explicit 12-state UI containers.
- `@relayquill/example-receiver` (`rc` authority), `@relayquill/example-provider-ingress` (`pi` authority for Stripe and Paystack test-mode webhook ingestion), and `@relayquill/example-producer`.

#### Database Migrations, Self-Hosted Infrastructure & Tooling (`migrations/*`, `infra/*`, `tools/*`)
- **PostgreSQL 18 & PGlite Migrations (`migrations/0001..0009`)**: Complete `rq`, `rq_support`, and `rq_recovery` schema definitions, `FOR SHARE` hot-path lock ranking on `installation_state` and `projects`, 16-shard `event_delivery_total_deltas` and `project_delivery_total_deltas` counters eliminating single-row `FOR UPDATE` bottlenecks, 58 public `SECURITY DEFINER` procedures (`SET search_path = pg_catalog`), and mechanically verified `migrations/privilege-manifest.json`.
- **Embedded Go NATS JetStream Launcher (`tools/broker-launcher`)**: Go `1.27.1` `relayquill-broker` binary enforcing handshake-first client TLS, 3-node cluster route mTLS with peer SAN verification, `SyncAlways` file storage, and scoped `relay` / `fanout` / `broker_admin` NKey ACLs.
- **100% Self-Hosted Production Topologies (`infra/`)**:
  - `infra/compose.prod.yaml`: Self-hosted production Docker Compose stack (PostgreSQL 18 with TLS and `SCRAM-SHA-256`, 3-node `relayquill-broker` quorum, non-root `uid 10001` Node workers, `uid 101` Nginx console reverse proxy, read-only root filesystems, and isolated internal/egress bridge networks).
  - `infra/kubernetes/`: Base manifests, independent `receiver` and `ingress` workloads, migration/recovery jobs, vendor-neutral `infra/kubernetes/overlays/selfhosted/` Kustomize overlay (PostgreSQL 18 StatefulSet, 3-node broker StatefulSet, default-deny `NetworkPolicy`, `PodDisruptionBudget`), and optional `overlays/eks/` and `infra/aws/` Terraform modules.
- **Verification & Operational Tooling (`tools/*`, `tests/*`)**: Import boundary verifier (`tools/verify-import-boundaries.mjs`), repository hygiene scanner (`tools/check-hygiene.mjs`), SDK bundler and isolated tarball consumer test (`tools/build-sdk.mjs`, `tools/pack-sdks.mjs`), release/cluster/recovery/load/diagnostic tools (`tools/release/*`, `tools/cluster/*`, `tools/recovery/*`, `tools/load/*`, `tools/operations/*`), PGlite SQL contract suite (`tests/contracts/*`), and multi-tier Playwright + PGlite E2E runner (`tests/e2e/run.mjs`).
